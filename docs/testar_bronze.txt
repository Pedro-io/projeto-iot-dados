========================================
 TESTES — ETLs Camada Bronze
========================================

PRÉ-REQUISITOS
--------------
1. Stack Docker rodando:
   cd infra/docker && docker compose --env-file ../../.env up -d

2. Verificar worker registrado:
   http://localhost:8085  (Spark Master UI)

3. Os scripts usam PYTHONPATH=/jobs (src/ montado em /jobs no container).
   Nenhuma configuração extra necessária — os imports já estão corretos.


VARIÁVEIS DE REFERÊNCIA (não são comandos, só para leitura)
-----------------------------------------------------------
EXEC_DATE   = 2026-06-18
ENV         = hmg
OWNER       = pedro
MONGO_URI   = mongodb://root:123@mongodb:27017/?authSource=admin
JDBC_URL    = jdbc:postgresql://postgres:5432/erp_database
JDBC_USER   = postgres
JDBC_PASS   = 123


FORMATO DOS COMANDOS
--------------------
Todos usam --master local[*] (modo desenvolvimento, sem enviar ao worker).
Troque por spark://spark-master:7077 para usar o cluster completo.


========================================
 MONGODB
========================================

--- 1. Equipamentos (MongoDB -> Bronze) ---
Extrai a coleção equipments, achata o struct factory e grava Delta em MinIO.

docker exec \
  -e MINIO_ROOT_USER=1234 \
  -e MINIO_ROOT_PASSWORD=12345678 \
  -e PYTHONPATH=/jobs \
  spark-master \
  /opt/spark/bin/spark-submit \
    --master local[*] \
    /jobs/processamento/bronze/mongo/equipamentos.py \
    --execution_date 2026-06-18 \
    --environment hmg \
    --owner pedro \
    --mongo_uri "mongodb://root:123@mongodb:27017/?authSource=admin" \
    --mongo_database Database \
    --mongo_collection equipments
