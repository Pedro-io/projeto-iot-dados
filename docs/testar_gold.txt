========================================
 TESTES - ETLs Camada Gold
========================================

PRÉ-REQUISITOS
--------------
1. Stack Docker rodando:
   cd infra/docker && docker compose --env-file ../../.env up -d

2. Silver populada - rode os ETLs da silver primeiro (docs/testar_silver.txt).
   A gold lê os Delta tables do bucket silver; sem silver não há dados.

3. Para as facts (fct_leituras_hora, fct_anomalias_dia) o ETL da silver
   kafka/sensor_events deve ter gerado dados com a data de execução abaixo.

4. Verificar worker registrado:
   http://localhost:8085  (Spark Master UI)


VARIÁVEIS DE REFERÊNCIA (não são comandos, só para leitura)
-----------------------------------------------------------
EXEC_DATE = 2026-06-22
ENV       = prd
OWNER     = pedro


FORMATO DOS COMANDOS
--------------------
Todos usam --master local[*] (modo desenvolvimento).
Não há parâmetros de conexão: a gold lê direto do bucket silver via S3A.


========================================
 DIMENSÕES
========================================

--- 1. Dim Equipamento ---
Faz join entre silver/postgres/equipamentos, silver/postgres/tipos_equipamento
e silver/mongo/equipamentos para montar a dimensão mestre de equipamentos (SCD Type 1).
Grava Delta em gold/dim/dim_equipamento.

docker exec \
  -e MINIO_ROOT_USER=1234 \
  -e MINIO_ROOT_PASSWORD=12345678 \
  -e PYTHONPATH=/jobs \
  spark-master \
  /opt/spark/bin/spark-submit \
    --master local[*] \
    /jobs/processamento/gold/dimensions/dim_equipamento.py \
    --execution_date 2026-06-22 \
    --environment prd \
    --owner pedro
