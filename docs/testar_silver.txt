========================================
 TESTES - ETLs Camada Silver
========================================

PRÉ-REQUISITOS
--------------
1. Stack Docker rodando:
   cd infra/docker && docker compose --env-file ../../.env up -d

2. Bronze populada - rode os ETLs da bronze primeiro (docs/testar_bronze.txt).
   A silver lê os Parquet/NDJSON do bucket bronze; sem bronze não há dados.

3. Para o teste de sensor_events (Kafka), o consumer bronze deve ter gravado
   NDJSON no bucket bronze com a data de execução usada abaixo.

4. Verificar worker registrado:
   http://localhost:8085  (Spark Master UI)


VARIÁVEIS DE REFERÊNCIA (não são comandos, só para leitura)
-----------------------------------------------------------
EXEC_DATE = 2026-06-19
ENV       = prd
OWNER     = pedro


FORMATO DOS COMANDOS
--------------------
Todos usam --master local[*] (modo desenvolvimento).
Não há parâmetros de conexão: a silver lê direto do bucket bronze via S3A.


========================================
 MONGODB
========================================

--- 1. Equipamentos (MongoDB -> Silver) ---
Lê bronze/mongo/equipamentos, aplica tipagem e dedup por equipamento_id.
Grava Delta em silver/mongo/equipamentos.

docker exec \
  -e MINIO_ROOT_USER=1234 \
  -e MINIO_ROOT_PASSWORD=12345678 \
  -e PYTHONPATH=/jobs \
  spark-master \
  /opt/spark/bin/spark-submit \
    --master local[*] \
    /jobs/processamento/silver/mongo/equipamentos.py \
    --execution_date 2026-06-19 \
    --environment prd \
    --owner pedro
